COURSEHUB - COURSE DUPLICATE FEATURE

How to run:
1. Open index.html in a browser.
2. Click Duplicate on any course.
3. The copy gets:
   - copied course details
   - a new unique slug such as full-stack-web-development-copy-2
   - Draft status
4. Use + Add Course to create another course.

Files:
- index.html
- style.css
- script.js
